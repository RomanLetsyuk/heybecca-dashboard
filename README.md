# HeyBecca — дашборд

Один самодостатній `index.html`. Усі дані всередині зашифровані **AES-256-GCM**
(ключ — PBKDF2-SHA256, 300 000 ітерацій). Без пароля сторінка не показує нічого.

## Що всередині
| Вкладка | Що показує |
|---|---|
| Огляд | вчора / 7 / 30 днів / місяць, порівняння з попереднім періодом або з торішнім, картки KPI, динаміка по днях, розріз по кампаніях |
| Прогноз місяця | факт з 1-го числа + прогноз до кінця місяця по витратах, покупках, цінності, ROAS, CPA; план і % виконання; скільки треба на день |
| Історія по місяцях | лют 2025 → сьогодні: витрати ₴/$, покупки, CPA, цінність, ROAS, ДРВ + GA4 + CRM |
| Воронка сайту | сеанси → перегляд товару → кошик → оформлення → покупка, CR на кожному кроці, розріз по каналах і джерелах, порівняння періодів |
| Ads ↔ GA4 | звірка кліків Ads із сеансами GA4 і конверсій Ads з транзакціями GA4 — по днях, місяцях і кампаніях |
| CRM | звірка «кабінет проти CRM» (потрібен доступ до таблиці клієнта) |

## Джерела
- **Google Ads API**, акаунт `3627812095`. Витрати показані з ПДВ (×1.2), як у звітності клієнта.
  Покупки — конверсія `Purchase (GA4)`; поруч довідково `Purchase (Custom)`.
- **GA4 Data API**, property `459735662`.
- **Курс USD** — офіційний НБУ на 15-те число кожного місяця.
- **CRM / план** — Google-таблиця клієнта (підключається через `HB_CRM_SHEET_ID`).

## Оновлення
```
./run.sh
```
Автоматично — щодня о 8:20 через launchd (`com.heybecca.dashboard`).

## Важливо
- `data/*.json` і `.dashboard_password` **ніколи не потрапляють у репозиторій** — заливається лише зібраний `index.html`.
- Пароль лежить локально у `.dashboard_password`. Щоб змінити — переписати файл і зібрати наново.
